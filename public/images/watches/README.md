# Watch Images Folder

## How to Add Watch Images

### Step 1: Save Your Images Here

Place all watch images in this folder:
```
public/images/watches/
```

### Step 2: Use the Correct Path in Admin

When adding a watch in the admin dashboard, use the image path format:
```
/images/watches/your-image-name.jpg
```

**Example**:
- Image file: `596442802_10163523036719836_2058931436498857665_n.jpg`
- Path to use: `/images/watches/596442802_10163523036719836_2058931436498857665_n.jpg`

### Image Requirements

**Format**: JPG, PNG, or WebP
**Size**: 1200x1200px minimum (square recommended)
**File Size**: Under 2MB per image
**Quality**: High resolution for luxury watch details

### Recommended Images per Watch

1. **Hero Shot** (dial front) - Primary image
2. **Wrist Shot** (shows size/presence)
3. **Case Back** (movement view if open)
4. **Side Profile**
5. **Clasp/Bracelet Detail**
6. **Box & Papers** (if included)
7. **Additional Angles** (bezel, crown, etc.)

### Quick Fix

If you don't have the image yet, you can:
1. Go to admin dashboard
2. Edit the DeepSea Dweller watch
3. Change the image URL to a temporary online image
4. Example: `https://images.unsplash.com/photo-1523170335258-f5ed11844a49?w=800`

### File Naming Best Practices

**Good**:
- `rolex-submariner-116610ln-front.jpg`
- `patek-philippe-nautilus-5711-dial.jpg`
- `ap-royal-oak-15500st-wrist.jpg`

**Bad**:
- `IMG_1234.jpg` (not descriptive)
- `watch photo.jpg` (spaces in filename)
- `New Image (2).png` (special characters)

---

**Need Help?**

If images aren't showing:
1. Check file exists in this folder
2. Check file name matches exactly (case-sensitive)
3. Check path starts with `/images/watches/`
4. Hard refresh browser: Ctrl + Shift + R (Windows) or Cmd + Shift + R (Mac)
